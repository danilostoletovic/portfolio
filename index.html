01 — HARDWARE MEETS SOFTWARE

YOLO Smart Vehicle

A Raspberry Pi 5 vehicle that sees the world with YOLO and takes instructions from a custom Android app. Computer vision, motor control, and live video — with actual wheels attached.

The interesting part: keeping camera capture, inference, and motor control separate so a busy vision pipeline doesn’t hold up the vehicle.

  • Python
  • Raspberry Pi 5
  • Kotlin / Compose
  • Docker
